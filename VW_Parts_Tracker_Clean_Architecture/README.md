# Volkswagen Parts Tracker Demo

Built with native Streamlit widgets, CSS, and Python session-state navigation. Only the supplied Polo GTI photo and Volkswagen logo are image assets.

## Demo login

## Run
```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

The order, route, locations, timestamps, and ETA are synthetic demo data. There is no Volkswagen production integration.
